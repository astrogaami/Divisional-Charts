About this Tool

This application combines two powerful modules:

  • Rectification Dashboard: Standard Vedic Charts (D1, D9, D10 etc.) using traditional calculation rules (Parashara). Ideal for birth time rectification.
  • Varga Explorer: A learning tool based on the "Parivritti" (Cyclical) method. It allows you to visualize any division (D1-D300) as a continuous loop.
